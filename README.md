# PT Adatama - Next.js Starter (pt-adatama-next)

Proyek starter Next.js sederhana untuk PT Adatama — katalog produk dinamis versi awal.
Desain: elegan minimalis dengan aksen hijau.

## Cara pakai (di mesin lokal)
1. Pastikan Node.js (v16+) terpasang.
2. Ekstrak folder `pt-adatama-next`.
3. Jalankan:
   ```bash
   npm install
   npm run dev
   ```
4. Buka http://localhost:3000

## Struktur singkat
- `pages/` — halaman Next.js (index.js & _app.js)
- `components/` — Header, ProductCard, Footer
- `data/products.js` — data produk dummy
- `public/` — logo & placeholder gambar produk
- `styles/globals.css` — styling global sederhana

## Deploy
Direkomendasikan deploy ke Vercel (hubungkan repo Git atau upload project).
